# 真机 vs H5 逐像素差异报告 · 第 4 轮

日期 2026-11-14。本轮真机与 H5 登录到同一台设备 `wl301010386256 / CF03`，设备差异不再干扰对照。

## 环境与口径

- 真机 SM-S9160，Android 17，`com.voistech.chat` 微喇，帧 738×1600。帧坐标 ÷1.9216 = CSS px，即 384 CSS 宽。
- H5 `main@e15aa0f`，DevServer 3021，ego-browser 视口 375×812，路由 `#/devices/1683740`。
- 真机坐标取元素树中心，H5 坐标取 `getBoundingClientRect`，两者都是 CSS px。
- 原生标题栏含状态栏。设备详情页标题中心 y=69.7，H5 为 28，差 41.7。报告同时给绝对值和以标题中心为锚点的相对值。相对值才是布局差异。原生字号是按墨迹高度和布局推定的 sp 值，H5 字号取自 computed style。
- 对比图 `pair-*.png` 把原生压到 375 宽，横向压缩 2.3%。像素结论以数字为准。
- 对齐图 `aligned-*.png` 按每屏标题中心裁剪原生，`diff-*.png` 是 4 倍放大的差异热图。
- H5 截图右侧绿色圆球是浏览器翻译插件，不是应用 UI。

| 发起聊天 CTA | 固定在底部，高 49.4，全宽绿底 | 无 | 缺 |

内容与状态差异：

- H5 用「卡 ICCID」和「卡片状态: 需充值」替代了原生的 IMSI 行，SIM 过期时间文案也不同。
- H5 的版本号用了接口的 `version`（完整固件串，换行成两行），原生显示的是 `sdk_version`（v1.6.0），这是信息卡高 +67.6 的主要来源。
- 接口响应没有 `imsi` 字段，H5 无法显示 IMSI，需后端补字段。
- 缴费充值：原生是橙色文字加橙色卡片角标，H5 是绿色小字，没有角标。
- 紧急联系人设置：原生文字为灰色但可点击，实测点进去能看到剩余 SOS 次数 5；H5 是正常黑色。这是样式差，不是禁用态。
- 同一台设备下，H5 仍渲染共享位置、位置和围栏、轨迹记录、轨迹上报设置、提醒和解除绑定，原生一屏都没有。两个账号都能管理该设备，但原生侧不展示位置能力，H5 侧接口标记为支持。按账号权限差异记录，待后端确认。

结构与控件差异：

- H5 多了「全选」行和每行右侧的圆形选择点，原生两者都没有。
- H5 列表包在白色圆角卡片里，原生行直接铺在页面底色上。
- H5 的搜索框比原生高 10px。上一轮把搜索框整体下移 36.7 的建议不成立，36.7 几乎全是状态栏偏移；两个搜索框的顶边相对标题是 44.3 与 44.0，已经对齐。
- 原生有 A–Z 索引，H5 没有。
- H5 底部有「添加 0 位联系人」，原生此页没有可见 CTA。
- 两侧好友数据不同：真机账号 6 人，H5 账号 5 人。抓包 `manager-get-all-friend` 返回 5 条，确认差异来自账号数据，不是 H5 过滤。
- 排序规则不同：原生为数字、拉丁、中文，H5 为数字、中文、拉丁。相同姓名集合下的顺序会不一致。

这一屏是当前最接近的一屏。标题墨迹原生 89.5×20.8，H5 89×21，字号一致。两张入口卡都是 48 高、间距 12。行中心相对标题分别是原生 68.2 / 128.0，H5 68 / 128。空态中心相对值 211.8 与 212。

唯一差异是头部右侧：原生有「简体中文」语言胶囊，H5 没有。原生这一屏的返回键贴左，中心 x 22.4，标题中心 y 61.4，比其他页面上移约 8px；H5 仍用统一头部，返回键中心 x 50、标题中心 y 28。按相对锚点看行位置对得上，头部本身不是同一套模板。

## 汇总

按「同一账号同一设备可直接修」排序：

1. 四个子页标题 24px 应为 18sp：设备详情、联系人管理、从通讯录添加、按条件查找添加。设备 tab 与群组管理保持 24，不动。
2. 详情页头像 64 应为 56，名称 16px 应为 18sp。
3. 详情信息卡字段：版本号改用 `sdk_version`，卡到期文案对齐原生。IMSI 受接口限制（响应无 `imsi`），需后端补。
4. 菜单行距统一到原生节奏 59.9 / 54.1，卡高 168 应为 155.6。
5. 搜索框高度：添加页 48 应为 38，条件搜索页 56 应为 37.5，条件搜索页补全宽输入框并去掉独立搜索按钮。
6. 添加页去掉「全选」行，行内头像左缘从 32 回到 15，头像 44 调到 49.4，名称起点 76.5。
7. 设备行：卡片改用淡绿、高度 67.6、左右缩进 32.3、名称 14sp、电池与 30% 放到第二行，去掉右侧箭头。
8. 联系人管理行去掉右侧箭头。
9. 群组管理补「简体中文」语言胶囊，或确认 H5 语言入口在别处。
10. 详情页补底部「发起聊天」CTA，缴费充值改为橙色文字加角标。
11. 紧急联系人设置行改为灰色文字。
12. 位置组与解除绑定：与后端确认 CF03 在 H5 账号下的能力标记，原生不展示。

范围外或需桥协议：原生添加设备卡、PTT、底栏、A–Z 索引、发起聊天（无桥协议时只能隐藏）。
